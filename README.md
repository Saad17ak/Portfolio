# Saad Khan Portfolio

Account manager and client success portfolio for Muhammad Saad Khan.

Open `index.html` in a browser served over HTTP (or enable GitHub Pages on this repo) so the page can load `data.json`.

- `index.html` – the portfolio page
- `data.json` – account, activity and client feedback data from the SimpleTalk Slack archive (client names removed)
- `shots/` – Slack conversation screenshots with client details blurred
